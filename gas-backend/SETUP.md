# วิธีติดตั้ง Backend บน Google Apps Script

ระบบนี้ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง — backend รันบน Google Apps Script (ฟรี) เก็บข้อมูล
ผู้ใช้/เอกสารใน Google Sheets และเก็บไฟล์ใน Google Drive ส่วน frontend (`/web`) เป็นไฟล์
static ล้วนๆ ที่ host บน GitHub Pages ได้ทันที

ขั้นตอนด้านล่างทำครั้งเดียว ใช้เวลาประมาณ 5-10 นาที **ขั้นตอนนี้ต้องทำเองในเบราว์เซอร์ที่ล็อกอิน
Google อยู่** เพราะเป็นการสร้าง/deploy ทรัพยากรในบัญชี Google ของคุณเอง ไม่มีเครื่องมืออัตโนมัติ
ไหนทำแทนได้

## 1. สร้าง Google Sheet + เปิด Apps Script

1. ไปที่ https://sheets.google.com สร้างสเปรดชีตเปล่าใหม่ 1 แผ่น ตั้งชื่อว่าอะไรก็ได้ เช่น
   "DocVault Data" (ชีตนี้จะเป็นฐานข้อมูล ระบบจะสร้างแท็บ Users/Sessions/Categories/Documents
   ให้เองอัตโนมัติ ไม่ต้องสร้างเอง)
2. เมนู **Extensions > Apps Script** จะเปิดหน้าต่างแก้ไขสคริปต์ขึ้นมา (ผูกกับชีตนี้โดยอัตโนมัติ)

## 2. คัดลอกโค้ด

ในหน้าต่าง Apps Script:

1. ลบเนื้อหาในไฟล์ `Code.gs` ที่มีอยู่เดิมออกทั้งหมด แล้ววางเนื้อหาจาก
   [`gas-backend/Code.gs`](./Code.gs) ในโปรเจกต์นี้ลงไปแทน
2. กดปุ่ม `+` ข้าง "Files" เพิ่มไฟล์สคริปต์ใหม่ (เลือกชนิด Script) ให้ครบตามรายชื่อนี้ แล้ววาง
   เนื้อหาจากไฟล์ที่ชื่อตรงกันในโฟลเดอร์ `gas-backend/` ของโปรเจกต์นี้:
   - `SheetDB.gs`
   - `Storage.gs`
   - `Auth.gs`
   - `Categories.gs`
   - `Documents.gs`

   (ตอนตั้งชื่อไฟล์ใหม่ใน Apps Script ไม่ต้องพิมพ์ `.gs` ต่อท้าย ระบบเติมให้เอง)

## 3. เปิดใช้งาน Drive API (Advanced Service)

1. ในแถบซ้ายของ Apps Script คลิก **Services** (ไอคอน `+`)
2. เลือก **Drive API** เวอร์ชัน `v3` แล้วกด **Add**
3. ตรวจว่า identifier เป็น `Drive` (ค่าเริ่มต้น) — โค้ดในโปรเจกต์นี้เรียกใช้เป็น `Drive.Files...`

ขั้นตอนนี้จำเป็นสำหรับฟีเจอร์ OCR/ตั้งชื่ออัตโนมัติ ถ้าข้ามขั้นตอนนี้ แอปยังใช้งานได้ปกติแค่จะ
ตั้งชื่ออัตโนมัติแบบสำรอง (เอกสารสแกน-วันที่) แทนเสมอ

## 4. Deploy เป็น Web App

1. มุมขวาบน กด **Deploy > New deployment**
2. กดไอคอนรูปเฟือง ข้าง "Select type" เลือก **Web app**
3. ตั้งค่า:
   - **Execute as:** Me (บัญชีของคุณ)
   - **Who has access:** Anyone
4. กด **Deploy**
5. ระบบจะขอ authorize สิทธิ์ — เลือกบัญชี Google ของคุณ ถ้าเจอหน้าเตือน "Google hasn't
   verified this app" (ปกติมากสำหรับสคริปต์ที่คุณเขียนเอง) ให้กด **Advanced > Go to
   [ชื่อโปรเจกต์] (unsafe)** แล้วกด Allow
6. คัดลอก **Web app URL** ที่ได้ (จะลงท้ายด้วย `/exec`) — นี่คือ endpoint ของ backend

> ทุกครั้งที่แก้โค้ดใน Apps Script ภายหลัง ต้องทำ **Deploy > Manage deployments > แก้ไข (ไอคอน
> ดินสอ) > Version: New version > Deploy** ใหม่ ไม่งั้นการแก้ไขจะไม่มีผลกับ URL เดิม

## 5. ตั้งค่า Frontend

เปิดไฟล์ [`web/js/config.js`](../web/js/config.js) แก้บรรทัดเดียว:

```js
const API_URL = "วาง Web app URL จากขั้นตอนที่ 4 ตรงนี้";
```

## 6. เปิด GitHub Pages

ใน repo settings ของ GitHub: **Settings > Pages** เลือก source เป็น branch ที่มีโค้ดนี้ (เช่น
`main` หลัง merge PR แล้ว) กับโฟลเดอร์ `/ (root)` จากนั้นเว็บแอปจะอยู่ที่

```
https://<username>.github.io/<repo>/web/
```

## หมายเหตุด้านความปลอดภัย/ข้อจำกัด

- รหัสผ่านเก็บแบบ salted SHA-256 (Apps Script ไม่มีไลบรารี bcrypt ให้ใช้) — ปลอดภัยเพียงพอสำหรับ
  การใช้งานส่วนตัว แต่ไม่แข็งแรงเท่า bcrypt/argon2
- ไฟล์ทุกไฟล์ที่อัปโหลดเก็บใน Google Drive ของบัญชีที่ deploy สคริปต์ (ไม่ใช่ Drive ของผู้ใช้แต่
  ละคน) แยกโฟลเดอร์ตาม userId และไม่ได้ตั้งค่าแชร์สาธารณะ — เข้าถึงได้ผ่าน API ที่ตรวจสอบสิทธิ์
  เท่านั้น
- จำกัดขนาดไฟล์ไว้ที่ 8MB/ไฟล์ (Apps Script Web App มีเพดานขนาด request/response ของตัวเอง)
- Apps Script ฟรีมี quota การใช้งานต่อวัน (เวลารันสคริปต์, จำนวนอีเมล ฯลฯ) เพียงพอสำหรับใช้งาน
  ส่วนตัว/ครอบครัวได้สบายๆ แต่ไม่เหมาะกับผู้ใช้จำนวนมาก
- ดาวน์โหลดไฟล์ทำงานฝั่งเบราว์เซอร์ล้วนๆ (ไม่มีเซิร์ฟเวอร์ตั้งชื่อไฟล์ผ่าน HTTP header ได้แบบ
  เวอร์ชัน Next.js) — บางเบราว์เซอร์/บางแพลตฟอร์มอาจตั้งชื่อไฟล์ที่ดาวน์โหลดเป็นภาษาไทยไม่สำเร็จ
  (เจอเป็น "download" เฉยๆ) เนื้อหาไฟล์ยังถูกต้องเสมอ แค่ชื่อไฟล์อาจไม่ตรงในบางกรณี
